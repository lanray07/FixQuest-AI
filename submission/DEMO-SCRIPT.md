# Demo script — target 2:45

Record on an actual Fire TV or accepted Fire TV/Vega simulator. Tablet test recordings are rehearsal material only. Use English speech or captions; no third-party music or footage. Record at 1920×1080 if available. Keep final duration below 3:00.

| Time | Screen and action | Narration |
|---|---|---|
| 0:00–0:15 | Home, visibly move focus with remote | “Meet FixQuest AI. Turn everyday home problems into interactive repair adventures. This is a learning game built for the living room.” |
| 0:15–0:30 | Choose a Mission, move across all three cards | “Explore a dripping tap, a slow sink, and a sticking door. Each room has five challenges, a practical puzzle, and a badge.” |
| 0:30–0:45 | Enter tap, show intro, start | “We begin by observing a model tap. The game builds confidence without pretending to diagnose your home.” |
| 0:45–1:00 | Give an incorrect answer, show feedback, retry correctly | “A wrong answer is a chance to learn. QuestGuide explains the reasoning and lets us try again.” |
| 1:00–1:15 | Open hint; close; demonstrate Repeat | “QuestGuide uses curated offline guidance. It is not live generative AI. Optional system narration can read prompts and feedback.” |
| 1:15–1:40 | Complete cause/tool questions; solve three-tile sequence | “The remote is all you need. In this model we isolate the supply, verify it has stopped, then select the matching part. Real repairs depend on the fixture, and uncertainty means stopping for qualified help.” |
| 1:40–1:55 | Answer final tap question; show completion badge | “Correct decisions earn XP. Completion and perfect-run bonuses reward learning, while replay only updates your best record.” |
| 1:55–2:15 | Cut to door alignment puzzle; move marker to zero and check | “Different missions offer different interactions. Here we adjust a virtual door marker into the target. No real hardware is being diagnosed.” |
| 2:15–2:30 | Show progress, then narration setting | “Badges and scores stay on this device. Clear focus, large text, and optional narration keep the interface approachable.” |
| 2:30–2:45 | Return to home | “Three complete adventures. No login, backend, or API key. FixQuest AI makes everyday home knowledge a shared adventure.” |

## Operator cues
- Start a fresh test install for clean 0 XP footage if desired. Clearing app storage deletes local progress.
- Turn off app narration while recording spoken narration to avoid overlapping audio. Show the toggle and briefly enable it to demonstrate TTS if the device has a working voice.
- Tap correct options: kitchen tap → worn washer/seal → spanner/cloth → isolate → verify flow stopped → matching washer → ask plumber.
- Door correct options: gaps/hinges → visible screw → matching screwdriver → left three times → Check → qualified assessment.
- Edit between real captured scenes. Do not represent a mockup or tablet frame as Fire TV hardware evidence.
- Show or state the device/simulator identity at the beginning or in the description.
